PROJECT DETAILS

About this project

This project demonstrates a measurable Docker image-size reduction for a Python 3.12 Flask and PostgreSQL application. The comparison report is produced by compare_images.ps1 on the Docker host; the web app reads that JSON report and never accesses the Docker socket.
